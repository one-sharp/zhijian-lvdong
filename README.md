# 指间律动

音乐驱动的互动手势舞 Demo。

[打开体验](https://one-sharp.github.io/zhijian-lvdong/)

## 功能

- 两段真人手势舞教学，以及自由音乐动作路线。
- 音乐库、片段混音、本地音乐导入。
- 摄像头识别双手和上半身，五色指尖与拖尾辅助跟练。
- 实时动作与节奏评分、连击音效、结束成绩。
- 导出只含摄像头画面与音乐的练习视频，不包含应用指引或分数。

## 使用

使用电脑 Chrome / Edge 直接打开上方 HTTPS 链接，允许摄像头权限。先选练习，再点击“开启摄像头并评分”。首次识别需要下载模型并预热。

摄像头画面、动作识别、评分和视频生成在访客浏览器里完成；导入音乐和设置保存于各自浏览器，录制视频下载到设备。手机与微信内置浏览器尚需单独验证。评分是原型规则，交叉与遮挡仍可能产生误差。

## 部署

本仓库保存已构建的静态站点，使用 GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。不需要服务器程序或 npm 构建。

教学视频与依赖来源说明随站点保留；第三方依赖许可见 `vendor` 中的 LICENSE 文件。
